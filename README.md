## The stack
 
Python 3, Jupyter notebooks, `numpy`, `pandas`, `scikit-learn`, `matplotlib`, `seaborn`. GitHub Codespaces and Google Colab for the environment.
 
---
 
## How to run it
 
```bash
git clone https://github.com/Walter-Mokwena/machine_learning_projects.git
cd machine_learning_projects
pip install -r requirements.txt
jupyter notebook
```
