# machine_learning_projects

A growing collection of end-to-end machine learning projects, each focused on applying a specific technique or algorithm to a real-world problem. Built as part of my journey through a PGDip in Data Science at the University of the Witwatersrand, supplemented by self-directed study via ML Zoomcamp and Kaggle.

---

## Purpose

This repository serves two goals:

1. **Learning by doing** — each project is a hands-on application of a concept studied in lectures or self-study, from linear regression through to neural networks and beyond.
2. **Portfolio** — demonstrating practical ML skills to prospective employers, with clean notebooks, documented reasoning, and reproducible results.

---

## Repository Structure

```
machine_learning_projects/
│
├── linear_regression/          # Car price prediction, feature engineering, RMSE evaluation
├── classification/             # Binary and multi-class problems, confusion matrices
├── regularisation/             # Ridge, Lasso — combating overfitting
├── neural_networks/            # Feedforward networks, activation functions, backprop
├── data_preprocessing/         # Normalisation, standardisation, one-hot encoding
├── model_evaluation/           # Cross-validation, precision, recall, F1
└── utils/                      # Shared helper functions and plotting utilities
```

> Folders are added as new projects are completed. Each folder contains its own `README.md` with project-specific details.

## Tools & Stack

- **Language:** Python 3
- **Environment:** GitHub Codespaces / Google Colab

- **Notebooks:** Jupyter (`.ipynb`)

## Key Concepts Covered

- Supervised learning (regression and classification)
- Feature engineering and data preprocessing
- Model evaluation metrics (RMSE, accuracy, precision, recall, F1)
- Regularisation techniques to prevent overfitting
- Neural network architecture and feedforward computation
- Gradient descent and parameter updates

## How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/Walter-Mokwena/machine_learning_projects.git
   cd machine_learning_projects
   ```

2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. Open any project notebook:
   ```bash
   jupyter notebook linear_regression/car_price_prediction.ipynb
   ```
